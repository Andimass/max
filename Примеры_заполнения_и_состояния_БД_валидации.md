## 7. Состояния (стейт-машины)

**`validation_result.correction_status`** — жизненный цикл отклонения:
NEW → SENT → IN_PROGRESS → FIXED → REFORMED → CLOSED
- NEW — выявлено, не отправлено · SENT — отправлено, получен `task_id` · IN_PROGRESS — заявка в работе · FIXED — исправлено в источнике · REFORMED — РНУ переформирован по ФЛ · CLOSED — перепроверка прошла.

**`validation_result.result`** — DETECTED / NOT_DETECTED.
**`validation_result.cause`** — BUSINESS (ошибка данных) / TECHNICAL (источник не отдал).

**`validation_summary.validation_status`** — OK / WARNING / ERROR (роллап: есть ERROR → ERROR; иначе есть WARNING → WARNING; иначе OK).
**`validation_summary.send_readiness`** — NOT_READY → READY_TO_SEND → SENT.

**`validation_run.systemic_failure`** — false (норма) / true (пусто или превышен порог → `send_suppressed=true`, рассылка по ФЛ подавлена).

**`validation_sending_log.operation_status`** — SUCCESS / ERROR.
**`validation_check.status`** — ACTIVE / INACTIVE.

| Шаг | Событие | validation_result.correction_status | summary.validation_status | summary.send_readiness | sending_log |
|---|---|---|---|---|---|
| T0 | Прогон, ошибка V_004 выявлена | NEW | ERROR | NOT_READY | — |
| T1 | Отправлено в Валидатор, получен task_id | SENT | ERROR | NOT_READY | VALIDATION / SUCCESS |
| T2 | Заявка взята в работу | IN_PROGRESS | ERROR | NOT_READY | — |
| T3 | Бухгалтер исправил, пришло уведомление о закрытии | FIXED | ERROR | NOT_READY | — |
| T4 | РНУ переформирован по ФЛ | REFORMED | ERROR | NOT_READY | — |
| T5 | Перепроверка: ошибки нет | CLOSED | OK | READY_TO_SEND | UOD / SUCCESS (ОК) |
